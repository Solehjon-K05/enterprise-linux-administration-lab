# Ticket 010 - Find Files and Directories

## Objective
Locate project files and directories using Linux search commands.

## Tasks Performed
- Located README.md.
- Listed all text files.
- Listed all directories.
- Displayed the README content.

## Commands Used

```bash
find ~/SpaceX -name "README.md"
cat README.md
find ~/SpaceX/Engineering/Falcon9 -name "*.txt"
find ~/SpaceX/Engineering/Falcon9 -type d
```

## Outcome
Successfully located and verified project files and directories.
